# Snake Game

## Overview

This project is a simple Snake game written in Python with `tkinter`.

The player controls a snake, collects food, grows longer, and tries to survive as long as possible without hitting the wall or the snake's own body.

## Features

- Clean graphical interface with `tkinter`
- Score counter
- Best score tracker for the current session
- Pause support
- Restart support
- Speed increases as the score grows

## Controls

- `Arrow Keys` or `W A S D`: Move the snake
- `Space`: Pause or resume the game
- `R`: Restart the game

## How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in the project folder.
3. Run:

```bash
python snake_game.py
```

## Game Rules

- Eat the red food to gain points and grow longer.
- Avoid hitting the walls.
- Avoid hitting your own body.
- The game ends when the snake crashes.

## Notes

- The game uses only the Python standard library.
- No extra installation is required.
